# Pup Quest

**Small paws. Big adventure.** An original, pixel-art browser platformer starring Biscuit the corgi.

**[Play Pup Quest](https://pallaviraiturkar0.github.io/pup-quest/)**

Run, jump, collect treats, and find the golden key to open the doghouse. Explore six handcrafted trails: Sunny Meadow, Mossy Hollow, Starlit Summit, Puppy Park, Seashell Shore, and Neon Nightwalk. Inspired by the approachable platforming of DOS-era games like Dangerous Dave, with entirely original code, levels, artwork, and synthesized sound effects.

## Controls

| Action | Keyboard | Phone / tablet |
| --- | --- | --- |
| Move | Left / Right or A / D | Hold the arrow buttons |
| Jump | Space, Up, or W | Hold JUMP |
| Pause / resume | Escape or P | Pause button |
| Restart adventure | R while paused | Restart adventure in the pause menu |

Hold jump for a higher leap; tap for a short hop. Jump on critters to bounce off them, and avoid spikes and water. Orange checkpoint flags save your position for the current trail. You start with three hearts and recover one on each new trail. Treats are optional; the golden key is required.

Sound starts off and can be enabled in the game toolbar. Your personal best and sound preference are saved on your device using local storage, when available. A reload starts a new adventure; checkpoints only last for the current run.

## Run locally

Requires **Node.js 20 or newer**. There are no dependencies to install.

```sh
npm start
```

Open `http://localhost:4173`. Use `PORT=8080 npm start` to choose another port. Serve the game over HTTP rather than opening `index.html` directly, since it uses JavaScript modules.

```sh
npm test
```

To lint, install the development tooling once with `npm ci` (the game itself has no runtime dependencies), then run:

```sh
npm run lint
```

The built-in Node test runner covers movement, variable jumps, coyote time, jump buffering, collisions, pickups, checkpoints, lives, pause/restart, and campaign state transitions. A full-campaign input replay also checks that all six trails can be completed without losing a heart, using ordinary movement and jumps. Level-data tests check every trail's bounds, themes, spawn point, hazard placement, and run a static jump-reachability check from the start to every platform, the golden key, and the doghouse.

## How it works

- `src/engine.js`: deterministic game rules and fixed-step physics.
- `src/levels.js`: six handcrafted trails and their collectible/platform layouts.
- `src/themes.js`: data-driven backdrops (palette, parallax layers, and ground decor) picked by each level's `theme`.
- `src/render.js`: original pixel artwork drawn at 480 x 256 and scaled without smoothing.
- `src/audio.js`: short, original sound effects generated with Web Audio.
- `src/main.js`: keyboard/multi-touch controls, menus, accessibility announcements, and saved scores.
- `styles.css`: responsive game page, with reduced-motion and fullscreen support.

No frameworks, downloaded assets, trackers, analytics, external fonts, backend, or paid services.

## Themed backgrounds

Every backdrop is drawn procedurally from data in `src/themes.js`: a palette plus an ordered list of parallax layers (sun or moon, stars, clouds, birds, sea, hills, dunes, city skylines, trees, palms, hedges, and street lamps). A level picks its backdrop with its `theme` field; unknown names fall back to the meadow. The first three trails use the meadow, forest, and starlit night; Puppy Park, Seashell Shore, and Neon Nightwalk use the **park**, **beach**, and **city** (night city) themes. Preview any theme on any trail with a query string, for example `?theme=beach` or `?theme=city`.

## Free hosting

The public repository uses **GitHub Pages**' built-in static publishing, with no custom workflow or build step. In repository **Settings > Pages**, **Deploy from a branch** is set to **main** and **/ (root)**, so GitHub publishes the site whenever `main` changes. The `.nojekyll` file tells Pages to serve the game directly without Jekyll processing.

Run `npm test` locally before publishing changes.

All URLs are relative, so the game works at the repository's `github.io/pup-quest/` address or another static host. Keeping the repository public allows GitHub Pages hosting on GitHub Free.
